# 🪔 Garba Night Ludo

### ✨ Where the spirit of Navratri meets the classic game of Ludo!

A festive, CSS-crafted Ludo board inspired by the vibrant colours, traditional decorations, and glowing lights of **Navratri**. This project transforms a classic board-game design into a digital celebration using only **HTML and CSS**, with no JavaScript required.

---

## 🌸 Project Preview

**Garba Night Ludo** brings together traditional Indian festive aesthetics and creative web design.

The interface features a colourful Ludo board, glowing festive lights, decorative torans, and a radiant mandala at the centre, creating a warm Navratri-inspired visual experience.

---

## 🎨 Features

* 🪔 **Navratri-Inspired Theme:** A festive design featuring traditional Indian colours and decorations.
* 🎲 **Classic Ludo Board:** A four-colour board with dedicated player zones and token designs.
* ✨ **Glowing Festive Lights:** Animated lights created using CSS keyframes.
* 🌿 **Decorative Torans:** Traditional-style hanging decorations built with HTML and CSS.
* 🪷 **Radiant Mandala:** A decorative central design with a glowing animation.
* 🎨 **Rich Colour Palette:** Deep purple backgrounds paired with pink, green, blue, golden yellow, and warm cream.
* 📱 **Responsive Layout:** Media queries help adapt the design to smaller screens.
* 💻 **Pure HTML & CSS:** No JavaScript or external libraries required.
* 🌟 **CSS Animations:** Subtle glowing effects bring the festive decorations to life.

---

## 🛠️ Tech Stack

| Technology           | Purpose                                                |

## 🪄 CSS Concepts Used

This project explores several fundamental and intermediate CSS concepts:

* **Flexbox:** Aligning and distributing board elements.
* **Radial Gradients:** Creating glowing backgrounds, textured player zones, and colourful tokens.
* **Keyframe Animations:** Animating the festive lights and central mandala.
* **Pseudo-elements:** Adding decorative details with `::before` and `::after`.
* **Clip-Path:** Shaping the four coloured triangles in the centre.
* **Positioning:** Layering decorative elements and arranging board sections.
* **Box Shadows:** Creating depth, glow, and layered borders.
* **Media Queries:** Adjusting typography and component sizes for smaller screens.
* **Aspect Ratio:** Maintaining a square Ludo board across different screen sizes.
* **CSS Transforms:** Positioning elements and adding subtle animation effects.

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone <your-repository-url>
```

**2. Open the project folder**

```bash
cd garba-night-ludo
```

**3. Run the project**

Open `index.html` in your preferred web browser.

You can also open the folder in Visual Studio Code and use Live Server to preview the webpage.
